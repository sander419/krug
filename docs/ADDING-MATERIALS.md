# Как добавить массу в библиотеку

Библиотека материалов — обычный массив в [`js/config/materials.js`](../js/config/materials.js).
Интерфейс строится из него сам: добавили запись — она появилась в списке, в фильтрах,
в расчётах усадки и массы, в ДНК-ссылке. Править разметку или CSS не нужно.

## Правило реестра

**Ни одного числа без первоисточника.** В карточку идут значения из паспорта поставщика
или производителя, а ссылка на источник кладётся в `src`. Всё, что посчитано или взято
по типу массы, перечисляется в `est` — интерфейс покажет рядом плашку «оценка».

Соглашение одно на все реестры: поле без паспортного значения попадает либо в `est`
(посчитано или взято по типу), либо в `unknown` (данных нет), либо в `na` (неприменимо).
Если паспорта нет совсем — запись не добавляем. Симулятор, который врёт числами, хуже,
чем симулятор без вашей любимой глины.

## Порядок

1. Найдите страницу товара с характеристиками: диапазон обжига, полная усадка,
   водопоглощение, доля и зерно шамота.
2. Скопируйте заготовку ниже в конец массива `MATERIALS`, заполните поля.
3. Добавьте источник в объект `SRC` вверху файла и сошлитесь на него.
4. Проверьте: `node tools/check-materials.mjs` — валидатор ловит противоречия
   (утиль горячее политого, водопоглощение растущее с температурой, цвета не hex,
   плотность вне разумного, отсутствующий источник).
5. Откройте приложение и посмотрите карточку глазами.

## Заготовка

```js
{
  id: 'vendor-name',              // латиница, цифры, дефисы. Попадает в ДНК-ссылку — не меняйте потом
  name: 'Название массы',
  vendor: 'Кто продаёт / производит',
  type: 'stoneware',              // terracotta | earthenware | grogged | stoneware | semiporcelain | porcelain
  grog: {percent: 0, grainMM: 0}, // шамот: доля и зерно в мм
  firing: {bisqueC: [900, 950], glazeC: [1200, 1230]},
  shrinkPct: 12,                  // полная усадка на рабочей температуре
  shrinkNote: 'как записано в паспорте',
  absorption: [                   // от холодного к горячему; больше точек — точнее подсказки
    {tempC: 1050, pct: 12},
    {tempC: 1230, pct: 2, note: 'необязательное пояснение'},
  ],
  moisturePct: 22,                // влажность поставки, если опубликована; иначе null
  colors: {raw: 0xb4643c, bisque: 0xc9825b, glaze: 0xa9c4b1},   // как показывать в 3D
  cte: 6.0,                       // КТР черепка ·10⁻⁶/°C — для вердикта по глазури
  uses: ['круг', 'лепка'],
  pack: 'упаковка 10 кг', priceRub: 1200,     // ориентир, не прайс
  note: 'Живое описание: как ведёт себя в руках, для чего брать, чего опасаться.',
  est: ['density', 'cte', 'colors'],          // посчитано или взято по типу
  unknown: ['moisturePct'],                   // данных нет, надо уточнить
  na: [],                                     // к этой записи неприменимо
  src: [SRC.вашИсточник],
}
```

## Откуда берутся производные величины

| Величина | Как получена |
| --- | --- |
| Плотность сырой массы | Считается из влажности: `ρ = 1 / (w + (1−w)/2.6)`, где `w` — доля воды по массе, 2.6 г/см³ — плотность глинистого вещества. При 22 % влажности выходит 1.92 г/см³. Если влажность не опубликована, берётся 22 % и поле помечается оценкой |
| «Посудная» | Водопоглощение на верхней температуре не выше 3 % |
| Цвета | Подбираются на глаз под фотографии черепка — это оформление, а не паспорт |
| CTE | Ориентир по типу массы. Нужен только для сравнения с глазурью, огневые пробы не заменяет |

## Совместимость ссылок

ДНК формы (`#dna=…`) версии 3 хранит `id` массы строкой. Старые ссылки версии 2 хранили
индекс массы из первой версии справочника — соответствие описано в `LEGACY_CLAY_INDEX`.
Поэтому **не переименовывайте `id` существующих записей**: сломаются ссылки, которые
люди уже сохранили. Название `name` менять можно.

## Что ещё расширяется так же

- **Принтеры** — `PRINTERS` в [`js/config/data.js`](../js/config/data.js): название, сопло,
  слой, подача, картридж, размеры камеры, примечание.
- **Пресеты форм** — `PRESETS` там же: иконка, имя, точки профиля.
- **Энциклопедия** — файлы в [`js/config/kb/`](../js/config/kb/), формат описан
  в `kb/index.js`, проверка `node tools/check-kb.mjs`.
